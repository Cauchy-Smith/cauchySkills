# 获奖论文风格（实测）

依据 `write/2022年`（第十九届，42 篇）与 `write/2023年`（第二十届，58 篇）共 **100 篇获奖论文**逐篇统计得出。这里写的不是偏好，是这 100 篇的实际共性。

## 一、实测基线

| 指标 | 最小 | 中位 | 最大 | 含义 |
| --- | --- | --- | --- | --- |
| 全文页数 | 23 | **61** | 138 | 获奖论文是「厚」的 |
| 正文页数（至参考文献） | 15 | **45** | 120 | 主体篇幅在这里 |
| 附录页数 | 1 | **9** | 72 | 代码与补充图表 |
| 图 | 0 | **21** | 85 | 图是主要表达手段 |
| 表 | 0 | **5** | 39 | 表用于结果与参数 |
| 参考文献 | 0 | **9** | 26 | 中英文混排 |
| 摘要字符数（去空白） | 608 | **999** | 1358 | |
| 带目录 | — | 67 / 100 | — | 三分之二有目录 |
| 摘要含「针对/对于问题N」逐问段 | — | 68 / 100 | — | 主流写法 |
| 分章「本章小结」 | — | 6 / 100（但每篇出现约 8 次） | — | 顶级论文的做法 |
| 多级附录（附录A/B/C） | — | 19 / 100 | — | 长附录分门别类 |

**结论**：页数与图数随**题量**缩放（固定部分约 12 页，每问约 9 页；每问约 4 张图、1 张表）：

```
页数下限 = 12 + 9 × 小问数      （4 问 → 48 页，接近获奖中位 61）
图数下限 = 4 × 小问数
表数下限 = 1 × 小问数
参考文献 ≥ 10 条
```

按 `check_format.py --questions N` 校验（默认 N=4）。低于下限说明工作量呈现不足，会报 `篇幅与量` WARN。

## 二、摘要的获奖写法

100 篇中 68 篇采用「逐问段」结构。标准四段式：

1. **背景段**（2–4 句）：领域价值 → 问题重要性。不要复述题目。
2. **总述段**：本文以 X 为对象，建立 Y 模型，采用 Z 方法，最终得到 W 结论。
3. **逐问段**：每段以「**针对问题一：**」或「**对于问题一，**」开头，段内走「目标/关键点 → 方法 → **具体数值结果**」。
4. **（可选）收尾段**：模型评估、创新点、应用价值。

**逐问段必须带具体数值**。对比：

- 弱：「问题一得到了较好的选址方案。」
- 获奖：「得到 A1~A4 数据集的板材利用率依次为 96.02%、94.08%、95.15% 和 94.08%。」
- 获奖：「目标 1 距离阵列相位中心 7.0303m，与阵列垂直方向夹角为 0.0011°。」

**方法名要写到全名＋缩写**：不写「启发式算法」，写「均匀三阶段排样方式的生成算法（TUSP 法）」；不写「神经网络」，写「BP 神经网络」。

**点出破题点**：获奖摘要常用「本问题的关键在于……」「破题点在于……」直白地告诉评委你抓住了什么。例：「本问题的关键在于订单组批」。

## 三、两种章节骨架

获奖论文有两种主流组织方式，**选一种，全篇统一**。

### 范式 A：统一章（模型集中）

```
1 问题重述        1.1 问题背景  1.2 问题提出  1.3 解题思路
2 模型假设与符号说明 2.1 模型假设  2.2 符号说明
3 基本模型        （各问共用的预备模型）
4 问题一、二的分析与求解  4.1 问题分析 4.2 问题一求解{4.2.1 数值求解 4.2.2 检验}
5 问题三的分析与求解
6 问题四的分析与求解
7 模型评价        7.1 优点  7.2 不足  7.3 展望
参考文献
附录A/B/C
```

适合：各问共用一套模型（如都基于 Bianchi 模型），先讲清基本模型再逐问应用。

### 范式 B：分问章（问题驱动）

```
1 问题重述        1.1 问题背景  1.2 问题提出
2 问题分析        2.1 问题一分析  2.2 问题二分析
3 模型假设
4 符号说明
5 问题一：模型建立与求解  5.1 模型建立 5.2 算法设计 5.3 模型求解 5.4 求解结果与分析
6 问题二：模型建立与求解
7 模型分析与评价  7.1 算法复杂度分析  7.2 模型优缺点分析
参考文献
附录  （9.1 补充图表  9.2 代码及注释）
```

适合：各问模型差异大（如问题一是整数规划、问题二是层次聚类）。

**共同点**（两种范式都必须有）：每问都走「**问题分析 → 模型建立 → 模型求解 → 结果分析 → 检验**」这一条链；模型假设与符号说明必须在正文前部；参考文献与附录在最后。

## 四、每问章内的标准小节

获奖论文在每问内部几乎固定地展开这几个小节，缺一项就是丢一个得分点：

| 小节 | 写什么 |
| --- | --- |
| 问题分析 | 关键矛盾点、解题思路框架、核心步骤 |
| 模型建立 | 变量定义、假设、公式推导（每步给物理意义） |
| 算法设计 | 算法流程、伪代码、复杂度 |
| 模型求解 | 工具、参数设置、初始化、收敛判断 |
| 结果与分析 | 具体数值 + 图表 + 与约束的匹配度 |
| **模型检验** | 独立成节：数值验证/仿真检验/交叉验证 + 误差指标 |

**「模型检验」要独立成节**，不要混在结果里一笔带过。获奖论文的写法是「4.2.1 数值求解 / 4.2.2 仿真检验」这样并列，把验证作为求解的对等环节。

**顶级论文每章末尾加「本章小结」**，用 3–5 句回收本章结论。

## 五、数据预处理

100 篇中有 43 处以「数据预处理」为标题的小节。当附件数据需要清洗（缺失、异常、量纲不一、特征构造）时，**独立成节**，写清：缺失值处理方法与依据、异常值检测方法与结果、标准化/归一化的选择理由、特征构造过程。`math-coder` 的 `results-report.md` 与 `solving/data/processed/` 提供了这些素材。

## 六、模型评价的获奖写法

模型评价是独立一章，其完整形态是：

```
优点（3–5 条，每条带证据）
不足/缺点（2–3 条，具体不空泛）
展望（可选）
```

再看两类**加分项**，出现在高水平论文里：

- **算法复杂度分析**：给出时间复杂度与空间复杂度，写成量级，如「空间复杂度为 O(nd)，时间复杂度约为 O(n³)」。优化类论文尤其要有。
- **精度评价与参数评价**：如用蒙特卡洛评估参数敏感性与模型精度，独立成小节。

写法对照：

- 弱：「本模型精度较高，效果较好。」（不得分）
- 获奖：「设置了几组数值实验进行定量性能分析，并选择了本场景下较优的算法。」
- 获奖：「配对算法会随着目标个数的增多提升算法的复杂度。」（缺点也具体）

## 七、图表

- 图是主要表达手段：中位 21 张。每问至少 4 张，覆盖不同侧面（结果图、对比图、收敛/误差图、敏感性图）。
- 表用于结果与参数：中位 5 张。参数表、结果表、检验指标表。
- 每张图/表**下方紧跟一句结论**，不要只贴图不说话。

## 八、附录

附录中位 9 页，两级结构：

```
附录A  <补充图表，如其他参数下的检验图>
附录B  ...
附录C  代码
```

代码用等宽字体、逐问分块、关键步骤加注释。中间计算结果与处理后的数据也要附。

## 九、语言风格

| 避免 | 改成 |
| --- | --- |
| 「效果较好」「精度较高」 | 具体数值：MAPE=2.34%、R²=0.9977 |
| 「神经网络」「综合评价」 | 全名：BP 神经网络、熵权法-TOPSIS |
| 「大概」「可能」「似乎」 | 确定表述，或明确标注为假设 |
| 「我们觉得」「笔者认为」 | 「本文采用……」「结果表明……」 |
| 空泛缺点「模型有局限」 | 「小样本下 K 不可辨识，变异系数达 2.047」 |

时态与主语：用「本文」「本节」作主语，动词用现在时陈述工作。
