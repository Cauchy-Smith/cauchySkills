# 格式规范（权威）

来源：项目内 `write/“华为杯”第二十三届中国研究生数学建模竞赛论文格式规范.docx` 与 `write/“华为杯”第二十三届中国研究生数学建模竞赛论文模板.doc`。本节是硬性要求，不是建议。

## 一、格式规范原文要点

- 从 A、B、C、D、E、F 题中任选一题。
- 论文题目、摘要和关键词写在**论文摘要页**上；摘要页的下一页开始**论文正文**。
- 论文从**摘要页**开始编页码，页码位于**每页页脚中部**，用阿拉伯数字从 **1** 开始连续编号。
- **不能有页眉**；论文中不能有任何可能显示答题人身份的标志。
- **论文题目用三号黑体字、一级标题用四号黑体字，并居中**。
- 论文中**其他汉字一律采用小四号宋体字**，**行距用单倍行距**。
- 摘要应简明扼要，需包含：**建模思路、主要方法、模型、结果与结论、创新点、关键词**；篇幅**一般不超过两页**，无需译成英文。
- 引用别人的成果或公开资料，必须在正文引用处和参考文献中明确列出；**引用程序须注明来源**。正文引用处用方括号标示编号，如 `[1][3]`；**引用书籍还必须指出页码**。
- 参考文献按**正文中的引用顺序**列出。
- 题目若有要求，计算结果和编程源程序需在规定时间内上传竞赛系统。

## 二、参考文献表述方式

规范原文给出的是下面这套**逗号分隔、无文献类型标识**的格式，本 skill 以它为准：

| 类型 | 规范原文格式 | 示例 |
| --- | --- | --- |
| 书籍 | `[编号] 作者，书名，出版地：出版社，起止页码，出版年。` | `[1] 王五，数学建模方法与应用，北京：高等教育出版社，56-78，2022。` |
| 期刊 | `[编号] 作者，论文名，杂志名，卷期号：起止页码，出版年。` | `[2] 张三，李四，城市交通流预测模型研究，系统工程学报，38(2)：189-201，2023。` |
| 网络 | `[编号] 作者，资源标题，网址，访问时间（年月日）。` | `[3] 国家统计局，年度数据，http://www.stats.gov.cn，2026年8月10日。` |

**注意**：项目内部分范文与写作提示词用的是 GB/T 7714 式（带 `[M]`/`[J]` 标识、`出版年:起止页码`）。两套都见于往届论文，但规范原文是上表这套。选定一套后**全篇统一**，不要混用；若题目或指导教师另有要求，从其要求。

## 三、模板结构（封面页 + 摘要页）

官方模板只有两页，其余由正文构成：

**封面页**（不编页码）

```
中国研究生创新实践系列大赛
“华为杯”第二十三届中国研究生
数学建模竞赛

        学　　校 | <学校>
        参赛队号 | <队号>
        队员姓名 | <姓名1，姓名2，姓名3>
```

**摘要页**（页码 1）

```
题目：<论文题目>

摘　要：
<摘要正文>

关键词：<关键词1；关键词2；...>
```

**正文**（页码连续）

## 四、字号对照与 builder 映射

中文号数 → 磅值：三号=16pt，四号=14pt，小四=12pt，五号=10.5pt。

| 元素 | 规范 | `build_paper.py` 取值 |
| --- | --- | --- |
| 论文题目 | 三号黑体，居中 | `黑体 16pt`，居中 |
| 一级标题 | 四号黑体，居中 | `黑体 14pt`，居中 |
| 二级/三级标题 | 其他汉字 → 小四宋体 | `宋体 12pt` 加粗，左对齐 |
| 正文 | 小四宋体，单倍行距 | `宋体 12pt`，首行缩进 2 字符 |
| 图/表标题 | （规范未规定） | `宋体 10.5pt`，居中 |
| 参考文献 | （规范未规定） | `宋体 10.5pt`，悬挂缩进 |
| 程序代码 | （规范未规定） | `Consolas 10.5pt`，单倍行距 |
| 页眉 | 禁止 | 所有节页眉为空 |
| 页脚 | 页脚中部，阿拉伯数字 | 居中 `PAGE` 域，封面节无内容 |
| 页码起点 | 摘要页为 1 | 正文节 `pgNumType@start = 1` |

## 五、容易踩的坑

- 封面页**不能**出现页码；因此封面与摘要必须是不同的节，不能在同一个节里靠分页符糊弄。
- 页码必须用 Word 的 `PAGE` 域，直接写死数字在导出 PDF 后不会随分页变化。
- 页眉一旦写入任何内容（包括横线）就不合规；`build_paper.py` 显式清空所有节页眉。
- 「不得显示答题人身份」：正文、页眉、页脚、图表来源中都不要出现学校名或姓名；这些只出现在封面的信息表里。
- 摘要超过两页是硬伤，写完后必须用 `check_format.py --pdf` 复核。
