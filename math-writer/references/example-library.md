# 项目内写作参考库

写作前先看同类优秀论文的**章节骨架与图表密度**，但不要抄内容。三个位置分工不同：

| 位置 | 是什么 | 什么时候读 |
| --- | --- | --- |
| `write/‘华为杯’第二十三届…论文格式规范.docx` | 格式规范原文 | 每篇都依它，权威见 `format-spec.md` |
| `write/‘华为杯’第二十三届…论文模板.doc` | 官方封面页 + 摘要页模板 | 改动封面/摘要版式时 |
| `write/2022年/`、`write/2023年/` | **100 篇获奖论文**（第十九、二十届，按 A–F 题分目录） | 量化风格基线，见 `award-style.md`；**最强参考** |
| `write/2025 <A–F>题思路+参考文献+代码+成品论文/` | 2025 年真题的完整解题包 | 需要对齐章节写法、图表密度、附录组织时 |

**路径基准**：以上都相对**项目根**（同时含 `resource/`、`code/`、`write/` 的那一层）。定位规则见 `math-modeler/SKILL.md` 的「项目资产位置」。`write/` 有 1.8 GB，**换项目时不必随行**；缺了它，本文件与 `award-style.md` 直接跳过即可——统计结论已固化在 `award-style.md` 里，不必重新统计。

## 零、100 篇获奖论文（2022/2023）

这是全库最有价值的写作参考，因为它**可量化**：`award-style.md` 的全部基线（篇幅、图表密度、摘要四段式、章节范式）都从这 100 篇统计而来。

- 分布：`2022年/` 42 篇，`2023年/` 58 篇，按 `A/`、`B/`、`C题/`… 分目录，文件名为「题号+队号」，如 `2023年/A题/A23102470073.pdf`。
- 全部**带文本层**，可直接用文本工具读（与 2025 那批不同，无需看图）。
- 单篇 23–138 页（中位 61 页），**不要整篇加载**；按页取「摘要页 + 目录页 + 各章标题」即可完成风格对照。
- 用法：写之前抽 2–3 篇同题型的，只看四样——摘要怎么分段、每问章内有哪些小节、图表密度、模型评价怎么写的。**只看结构与密度，不看结论**（题目不同，结论无效）。

## 一、2025 年真题解题包

每题下按老师分目录（`C老师`、`Z老师`、`L老师`、`W老师`、`G老师`、`H老师`、`X老师`、`Y老师`），一个高质量包的典型内容：

```
第一部分：B题/
  B题思路分析Z老师.pdf
  B题初步模型建立Z老师.pdf
  B题算法推荐Z老师.pdf
第二部分：B题问题1-3模型求解文档/
  问题一数学模型建立与求解-Z老师.pdf
  问题二数学模型建立与求解(用于写代码)-Z老师.pdf   ← 与 model-contract.md 同角色
第二部分：B题问题1-3代码与结果可视化/code/
  问题一代码.py  问题二代码.py  问题三代码.py
  Problem2_Results.xlsx  Valid_Results.xlsx
  特征重要性排序.png  模型性能评估.png  ...
```

`2025 C题…/L老师/C题 问题代码包-L老师/` 的命名最规整：`main_q1.m`~`main_q4.m`，结果在 `结果呈现/`，图名如 `问题1-结果图像-图1-1.png`、`问题3-可视化-图3-3.png`、表名如 `问题2-表1-正弦参数.csv`——**文件名直接对应论文图/表编号**，写作时按这个编号写「如图1-1所示」即可对上。

### 取用建议

- **学结构**：翻 `成品论文` 的目录页与各章标题，看一篇 60 页论文如何分配篇幅——模型建立与求解通常占正文一半以上。
- **学图表密度**：每问至少 4 张图 + 1 张表（100 篇获奖论文中位：全文 21 张图、5 张表）；图表下方都跟一句结论。
- **找文献**：各题 `参考文献/` 目录下是真实的期刊论文 PDF（中英文都有），可作为本队参考文献的**来源参考**，但要按 `format-spec.md` 的格式重排，并确认真的读过、正文真的引用过。

### 重要限制

`write/` 里绝大多数 PDF 是**扫描图片，没有文本层**（`成品论文` 尤甚，用文本工具读出来是空的）。想参考它们时：

- 不要试图用文本提取读内容——直接看页面图像。
- 可直接读文本的少数文件是 `思路分析`/`建模求解` 类的部分 PDF（如 `2025 C题…/W老师/…完整版….pdf`、`2025 E题…/X老师/E题问题一二三四-X老师.pdf`），其余按图片处理。
- 篇幅大（单文件 10–60 MB），**按需翻页**，不要整篇加载。

## 二、不要混淆的两个库

- `write/` —— 优秀论文与写作素材（本 skill）。
- `code/` —— 45 个组合模型案例源码（题目 + 代码），是**编程手**的素材库，索引在 `math-coder` 的 `references/example-library.md`。写作时若要在附录说明算法来源，可引用其中的模型名，但代码本身从 `solving/code/` 取。
